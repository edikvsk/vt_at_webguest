## Часто задаваемые вопросы

### Q: Как настроить камеру Logitech?
**A:** Используйте динамическое определение:
```powershell
$env:USE_DYNAMIC_MEDIA_DETECTION = "true"
$env:CAMERA_FOR_SELECTION = "Logi"
```

### Q: Почему не работает автоматическое определение?
**A:** Проверьте список устройств: `python scripts/detect_media_devices.py --list`

### Q: Как проверить конфигурацию?
**A:** Выполните: `py -3 -c "from utils.config_manager import config; config.print_config_summary()"`

### Q: Где найти логи?
**A:** Логи сохраняются в папке `logs/` с временными метками

## Поддержка

При возникновении проблем:
1. Проверьте [устранение неполадок](MEDIA_DEVICES.md#устранение-неполадок)
2. Изучите логи в папке `logs/`
3. Запустите тестовые скрипты для диагностики
